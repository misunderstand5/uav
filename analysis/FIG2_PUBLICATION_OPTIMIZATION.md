## 1. IEEE 官方图表要求（调研结果）

来源：IEEE Author Center, “Create Graphics for Your Article” / “Resolution and Size” / “File Formatting”。

### 1.1 尺寸
- **单栏宽**：3.5 in（88.9 mm）。
- **双栏宽**：**7.16 in（182 mm）**。
- 最大尺寸：7.16 × 8.8 in。
- 不要小于单栏宽；IEEE 可以缩小，但很难放大而不损失质量。

### 1.2 分辨率与格式
- 优先 **矢量**：PS / EPS / **PDF**。
- 非矢量：彩色/灰度 **>300 dpi**；黑白线条 **>600 dpi**。
- 可接受：PDF、PNG、TIFF；不接受 GIF/BMP/VSD。
- 文件命名：作者姓前 5 字母 + 序号，例如 `zhang2.pdf`。

### 1.3 字体
- 推荐：**Helvetica、Arial、Times New Roman、Cambria、Symbol**。
- **全文/全图字体一致**；PDF/EPS 要**嵌入字体**或转曲。
- **Type should appear approximately 9–10 point when viewed at full size.**
  - 这是最关键的一条：不是“画布上 9 pt”，而是**印在 7.16 in 宽时看起来 9–10 pt**。

### 1.4 色盲/灰度
- 不要只靠颜色区分；同时用**线型/形状/亮度**。
- 必须能在**灰度打印**下读懂。
- 不同元素用颜色 + 亮度对比。

### 1.5 对我们图的直接约束
- 画布必须是 **7.16 in 宽**（或 3.5 in 单栏，但三栏内容放不下）。
- 所有文字在 7.16 in 下 **≥6.5–7 pt**；标题 8–9 pt。
- 输出 **PDF 矢量** + 600 dpi PNG 预览。
- 字体用 Arial/Helvetica（matplotlib 用 DejaVu Sans 接近，但正式版建议 Arial）。
- 颜色用 Okabe–Ito 色盲安全色，且保证灰度可读。

## 2. 论文级框架图的 10 条设计规则

1. **一栏一个信息**：A=环境，B=学习，C=调度；不要在一栏塞两个故事。
2. **阅读顺序明确**：左→右、上→下；`s_t` 进、`a_t` 出、`z_t` 回。
3. **网格对齐**：所有 box 的边、标题基线、箭头端点对齐到同一网格。
4. **统一字号层级**：panel 8.5–9，box title 7.5–8，body 7，label 6.8；不再出现 5.6 pt。
5. **颜色有语义**：环境=灰绿，RL=蓝，调度器=橙；最多 3 个主色 + 灰。
6. **箭头不交叉**：主数据流实线，反馈/可选虚线；用直角折线，不用大弧线。
7. **图标简单**：线框/单色，不用 3D、阴影、渐变；4 个 M-UAV 可用 “×4” 省略。
8. **文字减法**：每个 box ≤3 行；公式只留 `w_i`、`A_i/B_i`、`1-swap` 三个。
9. **留白**：box 内边距 ≥0.08 in；栏间 ≥0.1 in；不要填满每个角。
10. **可灰度**：去掉颜色后，靠线型/填充深浅仍能区分 A/B/C。

## 3. 当前草图的审计（为什么不能直接进论文）

| 问题 | 现状 | 后果 | 修法 |
|---|---|---|---|
| **画布/字号** | 16×9 in 画布，body 5.6–8.4 pt | 缩到 7.16 in 后 body ≈2.5–3.7 pt，**印刷不可读** | 直接按 7.16 in 画，body 7 pt |
| **文字过多** | A3 三段、C1 四个公式、B4 四行 | 拥挤、字号被迫变小 | 每 box ≤3 行，公式减到 3 个 |
| **箭头交叉** | `a_M` 绕过 B1、`r_t` 横穿全图、`z_t` 穿 C 栏底部 | 阅读顺序乱 | 重新路由：`a_M` 走 B1 下方，`r_t` 走 B/C 之间，`z_t` 走 C 栏底部外侧 |
| **C 栏留白** | C1–C3 只占上半，底部空 | 视觉不平衡 | C 栏 box 下移/加高，或加 `slot n → n+1` 时间线 |
| **A1 拥挤** | 4 个 M-UAV + 3 簇 + 链接 | 图标重叠、标签挤 | 4 个 M-UAV 一排，簇用 3 个小圆，去掉单机标签 |
| **颜色/灰度** | 5 种颜色 + 虚线 | 灰度难区分 | 3 主色 + 灰；线型辅助 |
| **字体不统一** | DejaVu Sans，大小混杂 | 不像 IEEE 图 | Arial/Helvetica，统一字号 |
| **PDF 字体** | 未转曲/未嵌入 | 出版社可能缺字 | 转曲或嵌入 |

**最关键一条**：当前图在屏幕上“看起来还行”，是因为屏幕把 16 in 缩到 1700 px；但论文里是 7.16 in，字号会按比例缩小 2.23 倍。**必须按最终尺寸重画。**

## 4. 重设计规范（下一版按这个画）

### 4.1 画布
- **7.16 × 4.55 in**（双栏宽，高度约 4.5 in；TVT 一页可放）。
- 边距 0.04 in；栏间 0.06 in。

### 4.2 网格
- 左栏 A：x 0.04–2.18（2.14 in）。
- 右栏：x 2.24–7.12（4.88 in）。
  - B：y 2.36–4.51（2.15 in）。
  - C：y 0.04–2.26（2.22 in）。
- A1/A2/A3 高度约 1.5/1.25/1.4 in。
- B1 宽 0.95；B2/B3 各 0.95；B4 1.30。
- C1/C2 各 1.55；C3 1.40。

### 4.3 字号（最终印刷）
- Panel title：**8.5 pt bold**。
- Box title：**7.5 pt bold**。
- Body：**6.8–7.0 pt**。
- Equations：**7.2 pt**。
- Arrow labels：**6.8 pt**。
- 最小不低于 6.5 pt；能删的字就删。

### 4.4 颜色（Okabe–Ito 子集，色盲安全）
- 环境：`#00796B`（teal）边框 / `#F1F8F6` 填充。
- RL：`#0072B2`（blue）边框 / `#F2F7FC` 填充。
- 调度器：`#D55E00`（vermillion）边框 / `#FDF3E7` 填充。
- 反馈/次要：`#666666` 灰。
- 强调：`#E69F00`（orange）用于 `λ_s` / 1-swap。
- 灰度检查：teal/blue/vermillion 的亮度不同，黑白打印仍可分。

### 4.5 线宽
- Box 边框：0.6 pt。
- 主箭头：0.8 pt。
- 反馈/虚线：0.6 pt。
- 箭头头部：4–5 pt。

### 4.6 内容减法
| 栏 | 保留 | 删除/移到 caption |
|---|---|---|
| A1 | C-UAV、M-UAV ×4、GU 簇、500 m/K=4 | 5/20 MHz 细节 |
| A2 | 四阶段曲线、20→130、QoS 三档 | session 公式 |
| A3 | GU 速度、M-UAV 跟踪、age 更新 | Hungarian 细节 |
| B1 | relay tokens → encoder | 置换不变性公式 |
| B2 | π_M、Q_M、recursive | 网络层数 |
| B3 | π_P、Q_P、immediate | 功率映射公式 |
| B4 | replay、target、L_Q/L_π | 熵 α 细节 |
| C1 | `w_i`、`A_i/B_i`、λ_s | density 公式可放 caption |
| C2 | greedy、1-swap、feasible | 约束公式可放 caption |
| C3 | allocate、QSR/age update | 求和约束可放 caption |

### 4.7 箭头路由
- `s_t`：A→B，水平。
- `a_M`：B2 左侧→A1，从 B1 下方走，不穿 B1。
- `a_P`：B3 底部→C1/C2 之间，垂直+短折。
- `z_t`：C3 底部→A3，走 C 栏底部外侧（y=0.02 或 C 栏内底部）。
- `r_t`：A3 顶部→B4，走 B/C 之间的缝（y≈2.31），不穿 C 标题。

### 4.8 输出
- `fig2_framework.pdf`（矢量，字体嵌入/转曲）。
- `fig2_framework.png`（600 dpi 预览）。
- 文件命名按 IEEE：`zhang2.pdf`（如果你的姓是 Zhang；否则改）。
